# binexus Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A zero-dependency Node CLI (`binexus scan` / `apply` / `restore`) plus a `SKILL.md` that lets a user's coding agent walk them through pausing, stripping, or deleting dead projects and their orphaned background jobs.

**Architecture:** The scanner is read-only and writes `report.json`. The skill drives a conversation and writes `plan.json`. The applier is the only code that mutates anything, re-confirms every action, and moves deleted projects to `~/.binexus/trash`. Every side effect (shell commands, prompts, home dir, clock) is injected so tests never touch the real machine.

**Tech Stack:** Node 20+, ES modules, `node:test`, `node:fs/promises`, `node:child_process`. No runtime dependencies.

Spec: `docs/superpowers/specs/2026-10-22-binexus-design.md`

```js
import { mkdtemp, mkdir, writeFile, rm } from 'node:fs/promises';
import { tmpdir } from 'node:os';
import { join } from 'node:path';
import { execFile } from 'node:child_process';
import { promisify } from 'node:util';

const run = promisify(execFile);

export async function makeTmp() {
  const dir = await mkdtemp(join(tmpdir(), 'binexus-'));
  return { dir, cleanup: () => rm(dir, { recursive: true, force: true }) };
}

// Create files from a map of relative path -> content. Directories are
// created as needed. A value of null creates an empty directory.
export async function tree(root, files) {
  for (const [rel, content] of Object.entries(files)) {
    const abs = join(root, rel);
    if (content === null) { await mkdir(abs, { recursive: true }); continue; }
    await mkdir(join(abs, '..'), { recursive: true });
    await writeFile(abs, content);
  }
}

export async function git(dir, ...args) {
  const { stdout } = await run('git', ['-C', dir, ...args], {
    env: { ...process.env, GIT_AUTHOR_NAME: 't', GIT_AUTHOR_EMAIL: 't@t', GIT_COMMITTER_NAME: 't', GIT_COMMITTER_EMAIL: 't@t' },
  });
  return stdout.trim();
}

// Make `dir` a git repo with one commit. If `remote` is a path to a bare
// repo, push to it so the branch has an upstream.
export async function initRepo(dir, { remote } = {}) {
  await git(dir, 'init', '-q', '-b', 'main');
  await writeFile(join(dir, 'README.md'), 'x');
  await git(dir, 'add', '.');
  await git(dir, 'commit', '-qm', 'init');
  if (remote) {
    await git(dir, 'remote', 'add', 'origin', remote);
    await git(dir, 'push', '-q', '-u', 'origin', 'main');
  }
}

export async function bareRepo(path) {
  await mkdir(path, { recursive: true });
  await run('git', ['init', '-q', '--bare', '-b', 'main', path]);
  return path;
}
```

```js
import { readdir } from 'node:fs/promises';
import { join } from 'node:path';

const MARKERS = ['.git', 'package.json', 'pyproject.toml', 'Package.swift'];
const SKIP = new Set(['node_modules']);

export function isProjectDir(entryNames) {
  return MARKERS.some((m) => entryNames.includes(m)) || entryNames.some((n) => n.endsWith('.xcodeproj'));
}

export async function findProjects(root) {
  const found = [];
  async function visit(dir) {
    let entries;
    try { entries = await readdir(dir, { withFileTypes: true }); } catch { return; }
    if (isProjectDir(entries.map((e) => e.name))) { found.push(dir); return; }
    for (const e of entries) {
      if (!e.isDirectory() || e.name.startsWith('.') || SKIP.has(e.name)) continue;
      await visit(join(dir, e.name));
    }
  }
  await visit(root);
  return found.sort();
}
```

```js
import { execFile } from 'node:child_process';
import { promisify } from 'node:util';
import { access } from 'node:fs/promises';
import { join } from 'node:path';

const run = promisify(execFile);

async function git(dir, args) {
  const { stdout } = await run('git', ['-C', dir, ...args]);
  return stdout.trim();
}

export async function gitSignals(dir) {
  const none = { isGit: false, lastCommit: null, unpushedCommits: null, uncommittedChanges: false, hasUpstream: false };
  try { await access(join(dir, '.git')); } catch { return none; }

  let lastCommit = null;
  try { lastCommit = (await git(dir, ['log', '-1', '--format=%cI'])) || null; } catch {}

  let uncommittedChanges = false;
  try { uncommittedChanges = (await git(dir, ['status', '--porcelain'])) !== ''; } catch {}

  let hasUpstream = false;
  let unpushedCommits = null;
  try {
    await git(dir, ['rev-parse', '--abbrev-ref', '@{u}']);
    hasUpstream = true;
    unpushedCommits = Number(await git(dir, ['rev-list', '--count', '@{u}..HEAD']));
  } catch {}

  return { isGit: true, lastCommit, unpushedCommits, uncommittedChanges, hasUpstream };
}
```

```js
import { readdir, lstat } from 'node:fs/promises';
import { join, relative } from 'node:path';

export const ARTIFACT_NAMES = new Set([
  'node_modules', '.venv', 'venv', '.build', 'build', 'dist', 'DerivedData',
  '.next', '.turbo', '.cache', '__pycache__', '.pytest_cache',
]);

function isArtifact(name, siblingNames) {
  if (ARTIFACT_NAMES.has(name)) return true;
  return name === 'target' && siblingNames.includes('Cargo.toml');
}

export async function dirBytes(dir) {
  let total = 0;
  let entries = [];
  try { entries = await readdir(dir, { withFileTypes: true }); } catch { return 0; }
  for (const e of entries) {
    const p = join(dir, e.name);
    if (e.isSymbolicLink()) continue;
    if (e.isDirectory()) total += await dirBytes(p);
    else { try { total += (await lstat(p)).size; } catch {} }
  }
  return total;
}

export async function inspectTree(root) {
  const artifacts = [];
  let totalBytes = 0;
  let artifactBytes = 0;
  let newest = 0;

  async function visit(dir, countMtime) {
    let entries = [];
    try { entries = await readdir(dir, { withFileTypes: true }); } catch { return; }
    const names = entries.map((e) => e.name);
    for (const e of entries) {
      const p = join(dir, e.name);
      if (e.isSymbolicLink()) continue;
      if (e.isDirectory()) {
        if (isArtifact(e.name, names)) {
          const bytes = await dirBytes(p);
          artifacts.push({ path: relative(root, p), bytes });
          artifactBytes += bytes;
          totalBytes += bytes;
        } else if (e.name === '.git') {
          totalBytes += await dirBytes(p);
        } else {
          await visit(p, countMtime);
        }
      } else {
        try {
          const st = await lstat(p);
          totalBytes += st.size;
          if (countMtime && st.mtimeMs > newest) newest = st.mtimeMs;
        } catch {}
      }
    }
  }

  await visit(root, true);
  return {
    totalBytes,
    artifactBytes,
    artifacts,
    newestSourceMtime: newest ? new Date(newest).toISOString() : null,
  };
}
```

```js
import { readdir, readFile } from 'node:fs/promises';
import { join, basename, sep } from 'node:path';
import { execFile } from 'node:child_process';
import { promisify } from 'node:util';

const run = promisify(execFile);

function expandHome(token, home) {
  if (token.startsWith('~/') || token === '~') return home + token.slice(1);
  if (token.startsWith('$HOME/')) return home + token.slice(5);
  return token;
}

// Every whitespace-separated token that looks like a path, with ~ and $HOME expanded.
export function pathTokens(text, home) {
  const out = [];
  for (const raw of text.split(/\s+/)) {
    const tok = raw.replace(/^["']|["';&|]+$/g, '');
    if (tok.startsWith('/') || tok.startsWith('~') || tok.startsWith('$HOME/')) out.push(expandHome(tok, home));
  }
  return out;
}

export function parsePlist(xml, plistPath, home) {
  const strings = [...xml.matchAll(/<string>([^<]*)<\/string>/g)].map((m) => m[1]);
  const label = xml.match(/<key>Label<\/key>\s*<string>([^<]*)<\/string>/)?.[1];
  const paths = strings.flatMap((s) => pathTokens(s, home));
  return { kind: 'launchd', id: label || basename(plistPath, '.plist'), plist: plistPath, paths };
}

export function parseCrontab(text, home) {
  return text.split('\n')
    .map((l) => l.trim())
    .filter((l) => l && !l.startsWith('#'))
    .map((line) => ({ kind: 'cron', id: line.slice(0, 60), line, paths: pathTokens(line, home) }));
}

export function parsePm2(json) {
  let list = [];
  try { list = JSON.parse(json); } catch { return []; }
  return list.map((p) => ({
    kind: 'pm2', id: p.name, name: p.name,
    paths: [p.pm2_env?.pm_exec_path, p.pm2_env?.pm_cwd].filter(Boolean),
  }));
}

function inside(path, projectPath) {
  return path === projectPath || path.startsWith(projectPath + sep);
}

export function attachJobs(projects, jobs) {
  const unmatched = [];
  for (const job of jobs) {
    const owner = projects.find((p) => job.paths.some((path) => inside(path, p.path)));
    if (owner) owner.jobs.push(job); else unmatched.push(job);
  }
  return unmatched;
}

// Live collection. Each source fails soft.
export async function collectJobs({ home }) {
  const jobs = [];
  const agentsDir = join(home, 'Library', 'LaunchAgents');
  try {
    for (const name of await readdir(agentsDir)) {
      if (!name.endsWith('.plist')) continue;
      const p = join(agentsDir, name);
      try { jobs.push(parsePlist(await readFile(p, 'utf8'), p, home)); } catch {}
    }
  } catch {}
  try { jobs.push(...parseCrontab((await run('crontab', ['-l'])).stdout, home)); } catch {}
  try { jobs.push(...parsePm2((await run('pm2', ['jlist'])).stdout)); } catch {}
  return jobs;
}
```

```js
import { mkdir, rename } from 'node:fs/promises';
import { join, basename } from 'node:path';
import { execFile } from 'node:child_process';

// Run a command, optionally feeding stdin. Resolves stdout.
export function sh(cmd, args, input) {
  return new Promise((resolve, reject) => {
    const child = execFile(cmd, args, (err, stdout) => (err ? reject(err) : resolve(stdout)));
    if (input !== undefined) child.stdin.end(input);
  });
}

export function commentCronLine(text, line, date) {
  return text.split('\n').map((l) => (l === line ? `# binexus paused ${date}: ${l}` : l)).join('\n');
}

export async function pauseJob(job, deps) {
  const run = deps.sh ?? sh;
  if (job.kind === 'launchd') {
    try { await run('launchctl', ['bootout', `gui/${deps.uid}/${job.id}`]); } catch {}
    await mkdir(deps.pausedDir, { recursive: true });
    await rename(job.plist, join(deps.pausedDir, basename(job.plist)));
    return `unloaded ${job.id}; plist moved to ${deps.pausedDir}`;
  }
  if (job.kind === 'cron') {
    const current = await run('crontab', ['-l']);
    await run('crontab', ['-'], commentCronLine(current, job.line, deps.date));
    return `commented out cron line: ${job.line}`;
  }
  if (job.kind === 'pm2') {
    await run('pm2', ['stop', job.name]);
    return `pm2 stop ${job.name}`;
  }
  throw new Error(`unknown job kind ${job.kind}`);
}
```

```js
export async function deleteProject(project, { trashDir, date }) {
```

```js
export async function apply(plan, report, deps = {}) {
  const home = deps.home ?? homedir();
  const base = binexusHome(home);
  const d = {
    sh: deps.sh ?? realSh, prompt: deps.prompt ?? realPrompt, log: deps.log ?? console.log,
    date: deps.date ?? new Date().toISOString().slice(0, 10), uid: deps.uid ?? process.getuid?.(),
    recheck: deps.recheck ?? defaultRecheck, yesToStrip: deps.yesToStrip ?? false,
    pausedDir: join(base, 'paused'), trashDir: join(base, 'trash'),
  };
  const results = [];

  for (const entry of validatePlan(plan, report)) {
    const { action, project } = entry;
    const line = describe(entry);
    const push = (status, note) => { results.push({ path: project.path, action, status, ...(note ? { note } : {}) }); d.log(`${status.toUpperCase()}: ${line}${note ? ` — ${note}` : ''}`); };

    if (action === 'delete') {
      const now = await d.recheck(project);
      if (now.protected && !entry.acknowledgeProtected) { push('refused', 'project has unpushed or uncommitted work (or no git/upstream); set acknowledgeProtected: true in the plan to override'); continue; }
      if (!(await d.prompt.confirm(line))) { push('skipped'); continue; }
      if (now.protected && !(await d.prompt.typed(`${project.name} may contain work that exists nowhere else.`, project.name))) { push('skipped', 'name did not match'); continue; }
      try {
        for (const job of project.jobs) await pauseJob(job, d);
        const dest = await deleteProject(project, d);
        push('done', `moved to ${dest}`);
      } catch (e) { push('error', e.message); }
      continue;
    }

    if (action === 'strip' && project.artifacts.length === 0) { push('skipped', 'no artifacts'); continue; }
    if (action === 'pause' && project.jobs.length === 0) { push('skipped', 'no jobs'); continue; }
    const auto = action === 'strip' && d.yesToStrip;
    if (!auto && !(await d.prompt.confirm(line))) { push('skipped'); continue; }
    try {
      if (action === 'strip') await stripArtifacts(project);
      else for (const job of project.jobs) await pauseJob(job, d);
      push('done');
    } catch (e) { push('error', e.message); }
  }
  return results;
}
```

```js
#!/usr/bin/env node
import { readFile, writeFile } from 'node:fs/promises';
import { resolve, join } from 'node:path';
import { homedir } from 'node:os';
import { scan } from '../src/scan/index.js';
import { apply, binexusHome } from '../src/apply/index.js';
import { listTrash, restoreProject } from '../src/apply/trash.js';

const [cmd, ...rest] = process.argv.slice(2);
const flags = new Set(rest.filter((a) => a.startsWith('--')));
const args = rest.filter((a) => !a.startsWith('--'));
const mb = (b) => `${(b / 1048576).toFixed(0)} MB`;

const usage = `binexus — find dead projects and the jobs they left running. You decide.

  binexus scan [root] [--out report.json]   read-only, writes report.json
  binexus apply plan.json [--yes-to-strip]  confirms every action, then acts
  binexus restore [name]                    list trash, or restore one entry

Nothing is ever unlinked. Deleted projects go to ${binexusHome(homedir())}/trash.`;

async function main() {
  if (cmd === 'scan') {
    const root = resolve(args[0] ?? '.');
    const outIdx = rest.indexOf('--out');
    const out = outIdx >= 0 ? resolve(rest[outIdx + 1]) : resolve('report.json');
    process.stderr.write(`scanning ${root}\n`);
    const report = await scan(root, { onProgress: (p) => process.stderr.write(`  ${p}\n`) });
    await writeFile(out, JSON.stringify(report, null, 2));
    const by = (c) => report.projects.filter((p) => p.class === c);
    const withJobs = report.projects.filter((p) => p.jobs.length && p.class !== 'active');
    const artifactTotal = report.projects.reduce((s, p) => s + p.artifactBytes, 0);
    console.log(`\n${report.projects.length} projects: ${by('active').length} active, ${by('idle').length} idle, ${by('stale').length} stale`);
    console.log(`${mb(artifactTotal)} of regenerable artifacts`);
    if (withJobs.length) {
      console.log(`\nBackground jobs still running for idle/stale projects:`);
      for (const p of withJobs) for (const j of p.jobs) console.log(`  ${p.class.padEnd(5)} ${p.name}  <- ${j.kind}:${j.id}`);
    }
    if (report.unmatchedJobs.length) console.log(`\n${report.unmatchedJobs.length} user job(s) point outside ${root} (see unmatchedJobs in the report)`);
    console.log(`\nreport written to ${out}`);
    return;
  }
  if (cmd === 'apply') {
    if (!args[0]) throw new Error('usage: binexus apply plan.json');
    const plan = JSON.parse(await readFile(resolve(args[0]), 'utf8'));
    const reportPath = resolve(plan.reportPath ?? join(resolve(args[0]), '..', 'report.json'));
    const report = JSON.parse(await readFile(reportPath, 'utf8'));
    const results = await apply(plan, report, { yesToStrip: flags.has('--yes-to-strip') });
    const n = (s) => results.filter((r) => r.status === s).length;
    console.log(`\n${n('done')} done, ${n('skipped')} skipped, ${n('refused')} refused, ${n('error')} errors`);
    return;
  }
  if (cmd === 'restore') {
    const trashDir = join(binexusHome(homedir()), 'trash');
    if (!args[0]) {
      const items = await listTrash(trashDir);
      if (!items.length) { console.log(`trash is empty (${trashDir})`); return; }
      for (const i of items) console.log(`${i.name}  <- ${i.originalPath}`);
      console.log(`\nbinexus restore <name>`);
      return;
    }
    const dest = await restoreProject(args[0], { trashDir });
    console.log(`restored to ${dest}\nPaused jobs are not re-enabled. Plists are in ${binexusHome(homedir())}/paused; move one back to ~/Library/LaunchAgents and run: launchctl bootstrap gui/$(id -u) <plist>`);
    return;
  }
  console.log(usage);
  if (cmd && cmd !== 'help' && cmd !== '--help') process.exit(1);
}

main().catch((e) => { console.error(`binexus: ${e.message}`); process.exit(1); });
```

```markdown
name: binexus

# binexus

You are the brain. The `binexus` CLI is the hands. You never modify a project
or a job yourself. You scan, you ask, you write a plan. The user runs apply.

## 1. Scan

Ask which folder to scan if the user didn't say (default: `~/Documents` or
their projects folder). Run:

    npx binexus scan <root> --out <root>/binexus-report.json

Read the JSON. Each project has `class` (active | idle | stale), `protected`
(unpushed commits, uncommitted changes, no upstream, or not git), `artifacts`
(regenerable dirs with bytes), and `jobs` (launchd/cron/pm2 entries whose
paths point inside it).

## 2. Summary screen

Show one short summary:
- counts by class, total artifact MB
- every job attached to an idle or stale project, listed first: these keep
  running and the user has probably forgotten them
- `unmatchedJobs` in one line, no action

## 3. One project at a time

Order: stale with jobs, idle with jobs, stale by artifactBytes desc, idle by
artifactBytes desc. Skip active unless asked.

For each, show name, class, last activity date, size, artifacts, jobs,
protected flag, and your recommendation. Then ask the user to pick one:

- **keep** — nothing
- **pause** — stop its background jobs, touch nothing else
- **strip** — delete regenerable artifacts only (node_modules, .venv, build…)
- **delete** — move the whole folder to `~/.binexus/trash` (restorable)

If the user is unsure, offer to look inside (read README, git log, recent
files). You may read. You must not edit.

Protected projects: say what protects them. A delete needs the user to say

## 4. Write the plan

Write `<root>/binexus-plan.json`:

    {

      "reportPath": "<absolute path to binexus-report.json>",
      "actions": [
        {"path": "<absolute project path>", "action": "pause|strip|delete",
         "acknowledgeProtected": true}
      ]
    }

Only include projects the user chose an action for. Then tell the user:

    npx binexus apply <root>/binexus-plan.json

It confirms every action again before acting. Do not run it yourself.
```
